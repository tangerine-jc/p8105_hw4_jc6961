Data source and preparation

The dataset is ny_noaa from the p8105.datasets package, originally drawn from NOAA’s Global Historical Climatology Network Daily data. The complete course dataset covers 1981–2010. This dashboard filters it to January 1–December 31, 2010 before summarizing or sampling. Each row represents one station on one date.

Temperatures are stored as character values in tenths of a degree Celsius; I convert them to numeric values and divide by 10. Precipitation is in tenths of a millimeter and is also divided by 10. The resulting units are °C and mm.

In 9 records, the reported minimum exceeds the maximum. I set both temperatures in those records to missing while retaining their precipitation values. Missing measurements are excluded separately for each variable; they are never replaced by zero.

These counts use the 159,671 records in 2010 as their denominator. Some stations measure precipitation but do not measure temperature, so coverage differs substantially across variables.

How to read the charts

Line chart. Each point is a monthly mean of all nonmissing station-day measurements for that variable. Maximum and minimum temperatures can have different denominators. Hover text gives the number of contributing records.

Bar chart. Each bar is mean precipitation per observed station-day in a month, including observed zeros. This is not a monthly rainfall total. Hover text also shows the proportion of observed days with precipitation greater than zero.

Scatterplot. Each point is one of 4,000 randomly selected station-days with both temperatures observed and minimum no greater than maximum. Sampling is without replacement, using set.seed(6961). Seasons are winter (December–February), spring (March–May), summer (June–August), and fall (September–November).

Interpretation and limitations

The monthly temperature lines show a strong seasonal pattern, while the sampled temperature pairs show warmer minima and maxima during summer. The highest mean daily precipitation in this dataset occurs in October.

These are descriptive summaries of available station records. Stations with more observed days receive more weight; the set of reporting stations can change by month and variable. The charts are not area-weighted estimates for New York State, and one year cannot establish a long-term climate trend. Differences between months may reflect both weather and reporting coverage.

Reproducibility and references

The dashboard loads the package dataset directly. No downloads or package installations occur during knitting, and all charts run in the browser without a Shiny server. ```{r setup, include=FALSE}
library(dplyr)
library(plotly)

knitr::opts_chunk$set(echo = FALSE, message = FALSE)

data("ny_noaa", package = "p8105.datasets")

weather_df =
  ny_noaa |>
  filter(date >= as.Date("2010-01-01"), date <= as.Date("2010-12-31")) |>
  transmute(
    id,
    date,
    month = as.integer(format(date, "%m")),
    tmax = as.numeric(tmax) / 10,
    tmin = as.numeric(tmin) / 10,
    prcp = prcp / 10,
    invalid_pair = !is.na(tmin) & !is.na(tmax) & tmin > tmax,
    season = factor(
      case_when(
        month %in% c(12, 1, 2) ~ "Winter",
        month %in% 3:5 ~ "Spring",
        month %in% 6:8 ~ "Summer",
        TRUE ~ "Fall"),
      levels = c("Winter", "Spring", "Summer", "Fall"))) |>
  mutate(
    tmax = if_else(invalid_pair, NA_real_, tmax),
    tmin = if_else(invalid_pair, NA_real_, tmin))

monthly_df =
  weather_df |>
  group_by(month) |>
  summarize(
    n_tmax = sum(!is.na(tmax)),
    n_tmin = sum(!is.na(tmin)),
    n_prcp = sum(!is.na(prcp)),
    mean_tmax = mean(tmax, na.rm = TRUE),
    mean_tmin = mean(tmin, na.rm = TRUE),
    mean_prcp = mean(prcp, na.rm = TRUE),
    wet_percent = 100 * mean(prcp > 0, na.rm = TRUE),
    .groups = "drop")

set.seed(6961)
scatter_df =
  weather_df |>
  filter(!is.na(tmin), !is.na(tmax)) |>
  slice_sample(n = 4000)

coverage_df =
  weather_df |>
  summarize(
    `Maximum temperature` = sum(!is.na(tmax)),
    `Minimum temperature` = sum(!is.na(tmin)),
    Precipitation = sum(!is.na(prcp)))

# Shared styling keeps axes and hover text legible in each panel.
plot_font = list(family = "Trebuchet MS, sans-serif", size = 14, color = "#17324d")
